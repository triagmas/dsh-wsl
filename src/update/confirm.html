Update DeepSeek Harness

The DeepSeek Harness installed in your WSL distribution is updated in place with the exact published version. This is the same dsh that an ordinary dsh web in a WSL terminal runs.

This changes the shared WSL installation, not an app-private copy: a terminal started afterwards uses the new version too.

The DeepSeek Harness serving this window runs as the systemd unit —, which only root can stop. Type your WSL password once: the app installs exactly one line that lets it stop and start that single unit, and never asks again.

—

  • Only @deepseek-ai/dsh in that npm prefix is replaced; no other package is touched.
  • Your isolated data directory (DSH_HOME, sessions, settings, caches) is kept.
  • The official Windows app, your projects and your npm configuration are not touched.
  • If the update fails, the previous exact version is reinstalled and restarted.
  • The app restarts itself after a successful update.
